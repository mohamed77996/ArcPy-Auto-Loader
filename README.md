# ArcPy-Auto-Loader
A Python script to automate adding Point Feature Classes to ArcGIS Pro using ArcPy.
ArcPy Auto-Data-Loader
This script automates the process of adding Point Feature Classes to an ArcGIS Pro map by scanning a specific workspace.

Key Features:
Uses arcpy.da.Walk for efficient data scanning.
Includes error handling with try...except blocks.
Filters data by shapeType.
